## Status vocabulary

For this register. Not a claim that
Continuum was verified.

- ARCHITECTED: Designed and specified. No
  file necessarily exists.
- AUTHORED: The file exists and is
  complete.
- VALIDATED: Machine-validated against its
  schema.
- EXECUTED: Has actually run.
- VERIFIED AGAINST CONTINUUM: Has run
  against a real Continuum build and its
  result confirmed.
